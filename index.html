模 板 特 色

为「被记住」而设计

时光线叙事

中央时间轴串联 0-18 岁十九个节点，章节幕布划分「初生 / 学步 / 幼年 / 少年 / 青春」，翻阅如重走一遍成长。

每岁皆有注脚

每一年都有专属标题、记忆文字、时间与地点标签，照片再多，故事也不会散。

拍立得质感

相纸白边、轻微倾角、悬停抚平与灯箱大图——像把一沓老照片摊开在午后桌上。

丝滑动效

封面视差、滚动揭示、年份导航高亮、进度条——动效克制而流畅，不打扰，只加分。

手机完美适配

桌面左右交替、手机单侧时间线，照片自动重排，一屏一岁，指尖滑动即是回忆。

换肤即换气质

六行主题色变量控制全站配色，暖金、雾青、豆沙粉……一键切换整套气质。

D I Y 定 制

模板即成品，改起来很简单

每一位客户拿到手的不只是成品，更是可以自己继续更新的成长档案。

<img src="assets/…">

换照片

把新照片放进 assets/ 文件夹，替换对应年份的图片路径即可，拍立得相框自动适配。

.memory p

改文字

每段记忆、时间、地点都是独立文本，直接改写，年份导航与章节结构无需任何调整。

:root { --gold: … }

换主题色

页面顶部的六个颜色变量控制全站配色，想换气质，改一行就够了。

模板基于单文件 HTML + 相对路径图片，无构建、无依赖，双击即可打开，也便于后续发布上线。
