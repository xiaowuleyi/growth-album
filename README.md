# 时光集 · 成长相册

把孩子的 0—18 岁，装进一条时光线。

为每一个家庭定制「成长时光相册」：从出生到成年，每一年都有一张值得珍藏的照片、一段值得回望的文字、一个记得住的时间与地点。优雅大气，丝滑流畅，手机与电脑都好看。

## 内容组成

| 文件 | 说明 |
|---|---|
| `index.html` | 服务展示首页（含案例入口、模板特色、服务流程、DIY 说明） |
| `case-xiaoman.html` | 案例一「小满」· 男孩 · 暖金纪实：0-18 岁每岁 2-3 张照片（19 个年龄段 / 42 张图） |
| `case-zhixia.html` | 案例二「知夏」· 女孩 · 清新文艺：0-18 岁每岁 1 张照片（19 个年龄段 / 20 张图） |
| `assets/case-xiaoman/` | 案例一照片素材（cover + 0a-18c，JPEG） |
| `assets/case-zhixia/` | 案例二照片素材（cover + 0-18，JPEG） |
| `sync.sh` | 一键同步脚本：本地验证通过后提交并推送到 GitHub |

## 快速打开

双击 `index.html` 即可在浏览器打开。页面依赖同目录 `assets/` 文件夹，转发 / 部署时请连同目录一起发送。

## 页面特性

- 桌面 / 手机 / 平板双端适配，移动端自动切换为单侧时间线
- 顶部固定年份导航（0-18 + 序言 / 寄语），滚动时高亮当前年份
- 封面视差、滚动揭示动画、阅读进度条
- 照片灯箱：点击放大、键盘方向键切换、显示计数
- 尊重 `prefers-reduced-motion`，键盘焦点样式完整

## DIY 定制指南（给客户）

每个 HTML 文件顶部均有一段 `<!--` 注释块，按说明操作即可，无需任何代码基础：

1. **换照片**：把新照片放进 `assets/` 对应文件夹，替换相同年份的图片文件（保持文件名一致，或修改 HTML 中对应 `src` 路径）。拍立得相框会自动适配，无需调整其他内容。
2. **改文字**：每段记忆文字、标题、时间、地点均为独立文本，直接改写即可；年份导航与章节结构无需任何调整。
3. **换主题色**：页面顶部 `:root` 中的六个颜色变量（背景 / 纸张 / 墨色 / 金色等）控制全站配色，暖金、雾青、豆沙粉……改一行即可切换整套气质。
4. **增删内容**：每个年龄段是一个 `<article class="tl-row">` 块，复制 / 删除整块即可增删年份。

## 更新工作流（重要）

保持仓库与本地同步的标准流程：

1. 本地修改 HTML / 素材；
2. **本地验证**：桌面 + 手机两种视口打开检查（无报错、无溢出、图片完整、动画正常）；
3. 运行 `./sync.sh`，填写本次更新说明；
4. 脚本自动提交并推送到 GitHub；
5. 同时在 `CHANGELOG.md` 追加更新记录（重要改动务必记录）。

> 建议：每次对外交付前，在本地浏览器 + 手机各过一遍再同步。

## 部署上线

当前仓库为项目源码与模板资产。对外提供搭建服务时，可：
- 将单页 HTML 通过静态托管（如妙搭 / GitHub Pages / 任意静态服务器）发布为可访问链接；
- 每份客户定制 = 复制模板 → 替换照片与文案 → 换主题色 → 单独发布。
